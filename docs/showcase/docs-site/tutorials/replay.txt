Tutorials, replayed for real
==========================
Each tutorial of site/content/tutorials/ was followed step by step on a fresh production server (port 8794, empty data) with real input in headless Chrome:
mouse clicks at the element's place on the screen, key presses, characters typed one key at a time. window.edgy was read, never written.
The document each one builds was then compared with its template (src/core/tutorials.ts, tutorial-<name>): the cell trees with ids removed (kinds, names, props,
values, expressions, order), and both were shot in Live at 1280 wide and put side by side (<name>-side-by-side.png: the replay on the left, the template on the right).

Rerun: bash docs/showcase/docs-site/tutorials/replay.sh        (one tutorial: bash docs/showcase/docs-site/tutorials/replay.sh quote)
